# iedeGAME Local Launcher Linux Mobile版 2026-10-17

RG ARC・RG CubeXX・RG SP・RG35XXSP・RG34XXに対応しています。

## 新しくなったところ

### クライアントのテーマ変更に対応

- Linux Mobile版Local Launcherでも、クライアント画面のテーマを変更できるようになりました。
- クライアント画面の **Settings → Themes** から、**Default・ES-DE・Retro Glass** のテーマや配色を選べます。
- Top画面は一覧・カルーセル、ROM選択画面はタイル・詳細・カルーセルから表示形式を選べます。
- 設定はクライアントごとに保存されるため、同じサーバーを利用していても、それぞれ好みの見た目で使えます。

テーマ機能を利用するには、**サーバーとLinux Mobile版Local Launcherを最新版に更新してください。** テーマ機能に対応していない古いLocal Launcherでは、画面表示や操作が正しく動作しないことがあります。

# iedeGAME Local Launcher for Linux Mobile 2026-10-17

Available for RG ARC, RG CubeXX, RG SP, RG35XXSP, and RG34XX.

## What's new

### Support for client themes

- Local Launcher for Linux Mobile now supports changing the client interface's theme.
- Open **Settings → Themes** in the client interface to choose **Default, ES-DE, or Retro Glass**, along with your preferred color scheme.
- Choose a list or carousel for the Top screen, and tile, detailed, or carousel views when browsing ROMs.
- Settings are saved per client, so everyone connected to the same server can use their own preferred look.

To use themes, **update both the server and Local Launcher for Linux Mobile to the latest version.** Older versions of Local Launcher that do not support themes may not display or operate correctly.
