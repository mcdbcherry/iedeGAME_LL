# iedeGAME Local Launcher Linux Mobile版 2026-10-12

**対象バージョン：1.2610.1220**

RG ARC・RG CubeXX・RG SP・RG35XXSP・RG34XXに対応しています。

## 新しくなったところ

### 異なる機種で同じセーブデータを使って遊べます

- サインインしてRetroArchでゲームを起動すると、**サーバーからセーブデータを取得**し、
  保存した続きからプレイできます。
- 遊び終わってRetroArchを終了すると、未送信の変更がある場合に本体画面で更新を確認します。
  **「更新する」を選ぶと、プレイ後のセーブデータでサーバーを更新**できます。
- **同じサーバー・同じアカウントで同じゲームを起動すれば、異なる機種でも同じセーブデータで
  続きから遊べます。** 別のLinux Mobile機や、Windows・macOSのLocal Launcherで
  RetroArchを使う場合も共有できます。

### 設定画面にWi-FiのIPアドレスを表示します

- Local Launcherの設定画面の上部で、**端末のWi-Fi IPアドレス**を確認できるようになりました。
- Wi-Fiに接続していない場合やIPアドレスを取得できていない場合は、**「未接続 / IP未取得」**と表示します。

### 設定画面にバージョンを表示します

- Wi-Fi IPアドレスの上に、**実行中のLocal Launcherのバージョン**を表示します。
  設定画面から、使用しているバージョンを確認できます。

# iedeGAME Local Launcher for Linux Mobile 2026-10-12

**Version: 1.2610.1220**

Available for RG ARC, RG CubeXX, RG SP, RG35XXSP, and RG34XX.

## What's new

### Continue playing with the same save data across devices

- Sign in and launch a game with RetroArch to **download its save data from the server**
  and resume where you left off.
- When you finish playing and close RetroArch, an on-device confirmation appears if there are
  changes that have not been uploaded. **Choose "Update" to update the server with your latest save data.**
- **Launch the same game on the same server with the same account to continue with the same save data
  on another device.** Saves can also be shared with other Linux Mobile devices and with
  Local Launcher on Windows or macOS when using RetroArch.

### Wi-Fi IP address in Settings

- The **device's Wi-Fi IP address** now appears at the top of Local Launcher Settings.
- If Wi-Fi is disconnected or no IP address is available, **"Disconnected / No IP address"** is shown.

### Launcher version in Settings

- The **version of the running Local Launcher** appears above the Wi-Fi IP address,
  making it easy to check which version you are using.
