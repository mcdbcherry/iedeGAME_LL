# iedeGAME Local Launcher Linux Mobile版 1.2610.2101

RG ARC・RG CubeXX・RG SP・RG35XXSP・RG34XX・Miyoo Mini Plusに対応しています。

## 新しくなったところ

### 新しい機種への対応

- **Capcom CPS1・CPS2・CPS3、Neo Geo CD** に対応しました。Local Launcherから本体のRetroArchで起動できます。
- サーバーと、お使いの端末向けのLocal Launcherを最新版に更新してください。

### Miyoo Mini Plusへの対応拡張

- **Miyoo Mini Plus（Onion 4.3.1-1）** でも、**アーケード（Arcade）・Capcom CPS1・CPS2・CPS3・Neo Geo・PlayStation・PCエンジンCD・メガCD・Neo Geo CD** に対応しました。
- Miyoo Mini Plus版は専用UIを使用し、テーマ変更には対応していません。

## これまでの更新内容（2026-10-17）

### クライアントのテーマ変更に対応

- Linux Mobile版Local Launcherでも、クライアント画面のテーマを変更できるようになりました。
- クライアント画面の **Settings → Themes** から、**Default・Retro Showcase・Retro Glass** のテーマや配色を選べます。
- Top画面は一覧・カルーセル、ROM選択画面はタイル・詳細・カルーセルから表示形式を選べます。
- 設定はクライアントごとに保存されるため、同じサーバーを利用していても、それぞれ好みの見た目で使えます。

テーマ機能を利用するには、**サーバーとLinux Mobile版Local Launcherを最新版に更新してください。** テーマ機能に対応していない古いLocal Launcherでは、画面表示や操作が正しく動作しないことがあります。

# iedeGAME Local Launcher for Linux Mobile 1.2610.2101

Available for RG ARC, RG CubeXX, RG SP, RG35XXSP, RG34XX, and Miyoo Mini Plus.

## What's new

### Support for additional systems

- Added support for **Capcom CPS1, CPS2, CPS3, and Neo Geo CD**. Launch games through Local Launcher using RetroArch on your device.
- Update both the server and Local Launcher for your device to the latest version.

### Expanded support for Miyoo Mini Plus

- On **Miyoo Mini Plus running Onion 4.3.1-1**, added support for **Arcade, Capcom CPS1, CPS2, CPS3, Neo Geo, PlayStation, PC Engine CD, Sega CD, and Neo Geo CD**.
- The Miyoo Mini Plus version uses a dedicated interface and does not support changing themes.

## Previous updates (2026-10-17)

### Support for client themes

- Local Launcher for Linux Mobile now supports changing the client interface's theme.
- Open **Settings → Themes** in the client interface to choose **Default, Retro Showcase, or Retro Glass**, along with your preferred color scheme.
- Choose a list or carousel for the Top screen, and tile, detailed, or carousel views when browsing ROMs.
- Settings are saved per client, so everyone connected to the same server can use their own preferred look.

To use themes, **update both the server and Local Launcher for Linux Mobile to the latest version.** Older versions of Local Launcher that do not support themes may not display or operate correctly.
