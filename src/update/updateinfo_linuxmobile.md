# iedeGAME Local Launcher Linux Mobile版 2026-10-09

## 新しくなったところ

### 人気ゲームランキングを見られるようになりました

- 機種ごとの**ゲーム一覧の先頭にある「ランキングを見る」**から、人気・評価の高い
  ゲームを順位付きで見られるようになりました。
- 表示されるのは**接続先のサーバーにあるゲームだけ**です。ゲームの紹介文を読みながら、
  次に遊ぶゲームを探せます。
- ランキングからゲームを選ぶと、**いつもと同じように詳細を開いて起動**できます。
- 前の月のランキングがある場合は、**順位の変化**（▲3 / ▼1 / NEW）も確認できます。

### ランキングを使うには

- 接続先のサーバーを**ランキング対応版に更新**し、サーバーアプリの**「AI設定」**で
  GeminiまたはOpenAIのAPIキーを設定してください。
- **その機種のランキングが作成されると**、ゲーム一覧に「ランキングを見る」が表示されます。
  AIが未設定の場合や、ランキングがまだ作成されていない場合は表示されません。
- 順位と紹介文は**AIがネット検索をもとに作ったもの**です。誤りが含まれることがあります。

# iedeGAME Local Launcher for Linux Mobile 2026-10-09

## What's new

### Popular game rankings are now available

- Open **"View ranking" at the top of a system's game list** to see popular and highly rated
  games in ranking order.
- Only games **held on the connected server** are listed. Read the game descriptions to find
  something to play next.
- Select a game in the ranking to **open its details and launch it as usual**.
- When a ranking from the previous month is available, you can also see **changes in position**
  (▲3 / ▼1 / NEW).

### Using rankings

- **Update the connected server to a release that supports rankings**, then enter a Gemini or
  OpenAI API key in the server app's **AI Settings**.
- **Once a ranking has been created for that system**, "View ranking" appears in the game list.
  It stays hidden if AI is not configured or the ranking has not been created yet.
- The order and descriptions are **produced by an AI from a web search** and may contain errors.
